# Сайт ЦДУМ ПО (cdumpo.ru)

Новый официальный сайт **Централизованного духовного управления мусульман Пензенской области** (ЦДУМ ПО, муфтият Пензы). Заменяет текущий cdumpo.ru.

Перед любой работой прочитай `PRODUCT.md` (что за организация и для кого сайт) и `DESIGN.md` (как сайт выглядит и движется).

## Команды
```
pnpm dev          # localhost:3000
pnpm build
pnpm lint
pnpm typecheck
pnpm test         # Vitest (src/**/*.test.ts)
pnpm prayer:build # пересобрать src/data/prayer-times.json из data/prayer-times/*.json (после scripts/scrape-namaz.mjs)
pnpm screens /путь [папка]   # скриншоты страницы на 360/768/1280/1440 + проверка горизонтального скролла (нужен запущенный dev)
node scripts/sky-shots.mjs [папка] [390,1440]   # первый экран во всех пяти состояниях неба
```
Next.js 16 с `cacheComponents`: `new Date()`, `Math.random()` в серверном рендере ломают пререндер — всё, что зависит от текущего времени (виджеты намаза), живёт в клиентских компонентах (`lib/prayer/useNow.ts`). Перед работой с API Next.js сверяйся с `node_modules/next/dist/docs/` (см. `AGENTS.md`).

## Стек
- **Next.js 15+ (App Router) + React 19 + TypeScript.** React 19 обязателен: Payload 3 не работает на React 18.
- **Payload CMS 3** — админка внутри того же Next.js-проекта (`/admin`). Сотрудники сами ведут новости, видео, фото, сборы.
- **PostgreSQL** — база (`@payloadcms/db-postgres`). Локально — через Docker Compose, версия совпадает с продакшеном. Поиск по новостям — встроенный полнотекстовый поиск Postgres с русской конфигурацией, без отдельного поискового сервиса.
- **Tailwind CSS v4** — стили. Дизайн-токены из `DESIGN.md` задаются CSS-переменными через `@theme`.
- **Motion** — все анимации интерфейса. GSAP и Lenis **не используем**, скролл нативный (бюджетные Android, доступность).
- **Magic UI** — выборочно: Blur Fade, Text Reveal, Number Ticker, Dot Pattern, Border Beam. Ничего яркого «SaaS-стиля». Копируем только нужные компоненты и подгоняем под DESIGN.md.
- **Zustand** — подключать только при реальной необходимости клиентского состояния (например, выбранный город намаза). Данные с сервера идут через RSC, а не через стор.
- **Яндекс Метрика** — аналитика. Google Analytics и прочие зарубежные сервисы не используем.
- **pnpm** — пакетный менеджер.
- Хостинг — в России, уже есть. Подключаем после готовности сайта, доступы будут позже. Ничего, что требует зарубежных сервисов для работы сайта (без Google Fonts по CDN — шрифты self-hosted через `next/font/local` или `@fontsource`). Медиа из админки — в S3-совместимом хранилище (`@payloadcms/storage-s3`), а не на диске сервера.
- **Тесты:** Vitest — для логики (прежде всего `lib/prayer`), Playwright — для ключевых пользовательских сценариев.

## Правила работы
- Весь текст интерфейса — **на русском**, грамотно, с «ё» где нужно, кавычки «ёлочки», тире — длинное (—).
- **Не выдумывать факты об организации.** Имена, адреса, телефоны, суммы, даты — только из `PRODUCT.md` или от пользователя. Где данных нет — явная заглушка вида `[уточнить: телефон приёмной]`, а не правдоподобная выдумка.
- Арабский текст — только проверенный (басмала, известные аяты), всегда с `lang="ar" dir="rtl"` и русским смысловым переводом рядом.
- Изображения людей не генерировать. Фото — только реальные от муфтията; до этого — фирменные заглушки (силуэт мечети + орнамент).
- Каждая анимация уважает `prefers-reduced-motion`.
- Mobile-first. Проверять каждую страницу на 360 px, 768 px, 1280 px, 1440 px.
- Доступность WCAG 2.1 AA: контраст, фокус, зоны нажатия от 44 px, семантика.
- Перед тем как считать страницу готовой: `/impeccable audit <страница>` и `review-animations`, если на странице есть движение.
- Маленькие осмысленные коммиты на русском или английском, одна задача — одна ветка/PR.

## Объём первого релиза (MVP) — по концепции 2.0
Навигация — пять вкладок: Сегодня, Намаз, Мечети, Добро, Ещё (подробно — `PRODUCT.md`).
1. «Сегодня» (главная): небо по времени намаза с отсчётом, строка намазов, быстрые действия, созвездие Соборной мечети, «Жизнь уммы», ближайшие даты, слово муфтия. Тема светлая/тёмная — по небу.
2. Время намаза — город, неделя, таблица дня, месяц в PDF.
3. Мечети на карте — список, шторка мечети, маршрут.
4. «Небо добрых дел» для Соборной мечети — созвездие и пожертвование (СБП + карта). Нужны получатель, реквизиты и оферта от муфтията; до этого — макет без реальной оплаты.
5. «Жизнь уммы» — новости, видео и фото с фильтром; перенос старых новостей и редиректы.
6. «Муфтият» и контакты — история, муфтий, структура, документы, контакты и СМИ.

**Вторая очередь:** вопрос имаму, кибла-компас, обряды и запись, календарь хиджры, халяль, знания, закят-калькулятор, пятничная садака и другие сборы, Telegram-бот, PWA-напоминания.

## Время намаза
Источник — расписание муфтията (таблица), которое загружается через админку. Пока таблицы нет — расчёт библиотекой `adhan` с настраиваемыми параметрами, и на сайте пометка «предварительное время». Параметры расчёта сверить с муфтиятом до запуска.

## Логотип
`public/brand/logo.png` — растровый оригинал 747×709 с текущего сайта (используется в шапке); `logo-lowres.png` — старая копия, не использовать. Нужен оригинал в векторе (SVG/PDF/AI) от муфтията. До этого допустима аккуратная векторная перерисовка по образцу — **без изменения самого знака**.
