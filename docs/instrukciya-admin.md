# Как вести сайт: инструкция для сотрудников

Админка сайта — по адресу **cdumpo.ru/admin** (до запуска — `localhost:3000/admin`). Войти можно по почте и паролю, которые выдаёт администратор.

Есть две роли:
- **Редактор** — новости, видео, фотоальбомы, страницы, мечети, расписание намазов.
- **Администратор** — всё то же, плюс «Настройки сайта» (контакты, соцсети, баннер) и список сотрудников.

Главное правило: на сайт попадают только проверенные сведения. Если не уверены в имени, дате или цифре — уточните, прежде чем публиковать.

## Добавить новость

1. Слева — «Жизнь уммы» → «Новости» → кнопка «Создать».
2. **Заголовок** — коротко и по делу, без эмодзи и без заглавных букв во всю строку.
3. **Лид** — одно-два предложения: о чём новость. Его видно в ленте и в превью ссылки в мессенджерах.
4. **Обложка** — нажмите «Выбрать» и загрузите фото. У каждого фото обязательно **описание** — что на нём изображено, одной фразой (для слабовидящих и поисковиков). Если фото нет — не страшно: на сайте будет фирменная заставка с небом.
5. **Текст новости** — пишите как в обычном редакторе. Подзаголовки, списки, ссылки — через панель над текстом (выделите слово, появятся кнопки).
6. Справа: **рубрика**, **дата публикации** (по умолчанию — сейчас). **Адрес страницы** заполнится сам по заголовку — менять не нужно.
7. **Сохранить черновик** — новость сохранена, но на сайте её не видно. **Опубликовать** — новость сразу появляется в «Жизни уммы».

Снять новость с сайта: откройте её → справа меню «⋯» → «Снять с публикации». Удалять без нужды не стоит.

## Добавить видео

Само видео на сайт не загружается — оно живёт на **VK Видео** или **RuTube**.

1. Загрузите видео в сообщество муфтията на VK Видео или RuTube, скопируйте ссылку на него.
2. В админке: «Жизнь уммы» → «Видео» → «Создать».
3. Вставьте **ссылку** целиком (начинается с `https://`). Другие сайты админка не примет.
4. Загрузите **картинку-превью** — обязательно: по ней видео узнают в ленте. Подойдёт кадр из видео.
5. «Опубликовать».

Если к видео есть новость — в новости справа выберите его в поле «Связанное видео».

## Фотоальбом

«Жизнь уммы» → «Фотоальбомы» → «Создать» → название, дата события, затем «Добавить фото» для каждого снимка (у каждого — описание). Публикуется так же, кнопкой «Опубликовать».

## Загрузить расписание намазов

Расписание берётся из таблицы муфтията на год. Пока таблица не загружена, сайт показывает расчётное время с пометкой «предварительное время».

1. Подготовьте таблицу в Excel (`.xlsx`) или CSV. В первой строке — названия столбцов:

   | Дата | Фаджр | Восход | Зухр | Аср | Магриб | Иша |
   |---|---|---|---|---|---|---|
   | 15.10.2026 | 04:54 | 06:26 | 12:15 | 14:28 | 17:04 | 18:39 |

   Можно латиницей: `date, fajr, sunrise, dhuhr, asr, maghrib, isha`. Дата — `15.10.2026` или `2026-10-15`, время — `04:54`. Если есть столбец «Город», берутся только строки «Пенза».
2. Слева «Мечети» → «Расписание намазов».
3. В поле **«Файл с расписанием»** нажмите «Загрузить» и выберите таблицу. В поле «Откуда расписание» напишите, например, «Расписание муфтията на 2027 год».
4. «Сохранить». Таблица проверяется сразу: если в ней ошибка (нечитаемое время, дата дважды, времена не по порядку), появится сообщение с номером строки — исправьте файл и загрузите снова. Старое расписание при ошибке не пропадает.
5. После сохранения внизу видно, сколько дней в таблице. На сайте новое время появится в течение минуты.

## Мечети

«Мечети» → «Мечети» → «Создать»: название, город или район, адрес, координаты (в Яндекс Картах: правый клик по зданию → «Что здесь?» → первые два числа), имам, телефон, время джума (`13:00`), удобства, фото. Сведения — только от муфтията или имама мечети.

## Контакты и баннер (только администратор)

«Настройки» → «Настройки сайта»:
- **Контакты** — телефон приёмной, почта, часы приёма, контакт для журналистов. Пока поле пустое, на странице «Контакты» стоит пометка «[уточнить: …]».
- **Соцсети** — ссылки на Telegram и ВКонтакте.
- **Баннер-объявление** — короткое сообщение вверху внутренних страниц (например, о переносе джума). Поставьте галочку «Показывать баннер», введите текст, сохраните. Чтобы убрать — снимите галочку.

## Сотрудники (только администратор)

«Настройки» → «Сотрудники» → «Создать»: почта, пароль, имя, роль. Новому редактору передайте почту и временный пароль и попросите сменить его после первого входа (правый верхний угол → «Аккаунт»).
