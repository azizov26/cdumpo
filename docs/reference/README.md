# Референсы макетов

Статичные HTML-макеты из концепции (docs/concept-v1.pdf). Используй их как **визуальный ориентир** для вёрстки: сетка, пропорции, компоненты, виджет «Дуга солнца» (функция `ARC` в `common.js`), иконки.

Важно:
- Контент в макетах — от другой организации (dumpo.ru). Имена, новости, фонд «Радуга», муфтий — **не переносить**. Контент берётся из PRODUCT.md.
- Знак в макетах — условный. Используется логотип ЦДУМ ПО.
- Пути к шрифтам в base.css рассчитаны на старую папку и здесь не работают — это нормально.
