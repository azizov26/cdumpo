# Небо над Пензой — пакет для вёрстки (handoff v1)

Эталон для переноса дизайна в Next.js + Tailwind. **Главный источник правды — `js/sky-lib.js` + `css/*.css` + `screens.html`.** Все скриншоты в `screens/` сняты именно с них. Если PDF-концепция и этот пакет расходятся — верен пакет (отличия перечислены в конце).

Время, даты, суммы, имена на экранах — образцы для вёрстки, их заменяете реальными данными.

## Иконки

Нижняя панель: `today` (Сегодня), `namaz` (Намаз), `mosques` (Мечети), `dobro` (Добро), `more` (Ещё).
Быстрые действия: `mosques` (Мечети рядом), `ask-imam` (Вопрос имаму), `rites` (Обряды), `sadaqa` (Садака).
Кибла: `qibla`. «Зажечь звезду»: `light-star`. Остальные: bell, download, telegram, vk, calendar, arrow-right, chevron-down, back, close, search, phone, share, check, shield, drop, users, card, sbp-qr, book, moon, sun, play, heart, mosque.

## Солнце по состояниям (пример на макетах)

В проде угол считается от времени (`sunPoint` в `data/sky.ts`): 180° — восход, 0° — магриб.

| Состояние | Угол | Телефон (x, y) | Компьютер (x, y) |
|---|---|---|---|
| dawn | 172° | 12.8, 577.1 | 86.2, 686.5 |
| day | 80° | 226.9, 194.9 | 831.1, 179.1 |
| asr | 40° | 335.9, 349.5 | 1210.3, 384.3 |
| evening | 20° | 367.9, 485.4 | 1321.4, 564.8 |
| night | луна | 330, 190 | 1180, 170 |

Границы состояний: dawn — Фаджр→восход; day — восход→Аср; asr — Аср→(Магриб − 60 мин); evening — (Магриб − 60 мин)→Иша; night — Иша→Фаджр. Тема: day и asr — светлая, остальные — тёмная.

## Созвездие

`data/constellation.json`: `stars[]` — `id`, `x`, `y`, `order` (1 = зажигается первой, снизу вверх), `path`, `size` (множитель радиуса). `lines[]` — пары `id`. Звезда горит, если `order ≤ lit`, где `lit = round(120 · собрано / цель)` (`litFromProgress`).
Отрисовка (как в `drawConstellation`): горящая — ядро r = 3.4·size, `#FFE7B8` + ореол r ×3.2, `#F6CF96`, opacity .14; погашенная — контур r ×0.7, stroke rgba(255,240,215,.45) 0.8 px; линия между горящими — `#F6CF96` 1 px, opacity .55; иначе пунктир 2/4, 0.6 px, opacity .5. Новая звезда — кольца r ×4.5 (1.2 px) и ×8 (0.8 px, .5) + ядро r ×1.7 `#FFF6E0`. Полумесяц горит, когда зажжены все 120.

## Отличия пакета от PDF-концепции (исправлено здесь)

- Дуга компьютера: ry 560 → 600, текст опущен с 200 до 224 — дата больше не пересекает дугу.
- Созвездие пересчитано ровно на 120 звёзд с полем 24 px (в PDF было больше точек и обрезка по краю).
- Слои неба получили классы `sky-sun`, `sky-moon` — не путать с CSS-классами `.sun` / `.moon` из `sky.css`.
- В PDF ширины телефонов уменьшены через `zoom: .74`; все размеры здесь — 1:1.
